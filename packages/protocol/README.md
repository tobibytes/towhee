# @towhee/protocol

Messages, framing and shared types for [Towhee](https://towhee.madebytobi.com) clients and servers: access levels, room ids and patterns, comment bodies, versions, notifications, and close and error codes.

You get it through `@towhee/client` or a host package; import it directly for types like `CommentBody`, `Thread`, `Version` or `Notification`, or constants like `INBOX_ROOM`.

Docs: [towhee.madebytobi.com/docs/reference](https://towhee.madebytobi.com/docs/reference).
